SITE
1. Abra https://app.netlify.com/drop
2. Arraste ESTA PASTA (_public)
3. Copie o link ….netlify.app
4. Abra no PC e no celular

NUVEM (mesmos dados, sem token GitHub)
1. No PC, no app: Configurações → Nuvem fácil
   Escolha um PIN (ex: 4821) → Criar nuvem → Copiar o código
2. No celular, o mesmo PIN, cole o código → Entrar
3. Pronto. O que você salvar no PC sobe sozinho.

Não compartilhe PIN nem código. Prints não vão nesta nuvem
(arquivo ficaria grande); use Exportar JSON se precisar dos prints.

BÔNUS: backup por e-mail (opcional)
Configurações → Backup por e-mail → cole a URL do relay e o destino.
Como montar o relay (15 min, grátis): ferramentas/email-backup/LEIA-ME.md
(e o mapa do repositório: README.md · guias em docs/)
